# Task Tracker

Author: Ricardo Moreira

## Description

The Task Tracker is a small Java web application. It allows users to view a list of tasks and add new tasks through a web browser.

## Tech Stack

- Java
- Spring Boot
- Maven
- Thymeleaf
- Git and GitHub

## How to Run

Run the `Main` class from IntelliJ IDEA or use Maven to start the Spring Boot application.

The application is available at:

http://localhost:8080
